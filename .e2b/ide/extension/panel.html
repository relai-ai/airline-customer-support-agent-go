What you will do with RELAI
  1. Investigate: connect the scenario to the agent’s code and behavior.
  2. Create a test: turn your expected behavior into a repeatable check you can review.
  3. Evaluate: run the test and inspect the actual response, trace, and score.
  4. Optimize: use a measured failure to improve the agent and inspect the code changes.
  5. Verify: rerun the test and existing regressions to check the improvement and detect side effects.
