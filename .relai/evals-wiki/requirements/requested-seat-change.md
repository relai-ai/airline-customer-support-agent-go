# Apply requested seat changes

For a valid confirmation code and supported seat-change request, apply the requested change, confirm the result, and leave other booking details unchanged. The benchmark case changes SKY123 to 14C.

Confirmation must remain within [commercial evidence](relai://wiki/requirements/commercial-fact-grounding.md). The invalid-seat challenge adds [layout constraints](relai://wiki/requirements/challenge-seat-layout.md) within its scope.
